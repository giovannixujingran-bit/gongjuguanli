# presentation/ 说明文档 — 设计稿

> 日期：2026-06-08　状态：待实现
> 目标：把原 `deck.html`（8 页 scroll-snap 幻灯片，被评"想到啥讲啥、缺真流程图、缺运行方式"）重构为**一份可滚动的说明文档**（带固定目录/锚点的"可视化 README"），自己留档 + 多用。

## 1. 要解决的问题

原 deck 的毛病：① 各页是孤岛、缺贯穿的因果线，读起来"想到啥讲啥"；② 架构页是静态层叠图、无箭头数据流；③ 完全没有"运行方式/部署"视图；④ `presentation/` 下 `deck.html`/`index.html`（与 deck 字节相同的重复）/`styles.html`（旧三风格草稿）三个文件混乱。

## 2. 核心设计：用「三条核心原则」当贯穿全篇的筋

把三条原则提到全文最前当"镜头"，**后面每一节显式回扣它**（如数据契约回扣原则①、架构数据流回扣原则②、采集手段回扣原则③），让原则从"孤立一页"变成串起全文的逻辑线——这是治"没逻辑"的关键。

## 3. 形态

- 单文件、可滚动 HTML 文档；左侧/顶部**固定目录（TOC）+ 锚点跳转**。
- **保留**原 deck 的视觉系统（暖白 `#FCFBF8` / 深蓝 `#1A2B4A` / 砖红 `#C0563B`、Georgia+雅黑、细线分隔）；不重做视觉，只改信息结构。
- 纯 HTML/CSS，离线可开，不依赖外部库。
