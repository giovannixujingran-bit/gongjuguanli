# apps —— 两个前端

共用下面同一套后端，**互不 import**，只通过共享数据相连。同栈 React + Vite + TS。

| 子目录 | 是谁 | 职责 |
|---|---|---|
| `user-portal/` | 使用端 · 使用者门户 | 分类卡片、排序、AI 工具推荐、登录入口 → [工具门户](../../规划/使用端/工具门户.md) |
| `admin-dashboard/` | 数据端 · 后台分析台 | 明细查询、四类看板、接入/账号管理（可后置加 AI 数据分析助手） |

> 架构定位见 [架构与原则 §三](../../规划/总则/架构与原则.md)。
