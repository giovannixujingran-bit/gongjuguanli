# integrations —— 存放各个工具（接入适配）

每个接入本平台的工具，在此放**一个子目录**，存它的接入适配代码 / 配置 / 上报封装用法。

**工具本体不在这里**：工具各自独立部署，门户经 `launch_url` 局域网链接打开它们；本目录只放「怎么把这个工具接进平台」的那部分。

- `_template/` —— 接入模板，新工具照抄起步。
- 新增工具：复制 `_template/` → 改名为该工具目录 → 填接入配置，并在[工具注册表](../docs/registry.md)登记拿 `tool_id`。

> 接入方式（自报 / 转发 / key）见 [接入契约](../docs/contract.md) 与 [执行计划 Phase 5](../docs/execution-plan.md)。
