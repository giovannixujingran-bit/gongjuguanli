## 结构总览

按「**两个前端 + 共享后端 + 集成层**」组织（架构见 [规划/总则/架构与原则](../规划/总则/架构与原则.md)）：

| 目录 | 职责 | 对应规划 |
|---|---|---|
| `shared/` | 共享层：两端共用的 schema、生成模型、工具注册表 | [共享层](../规划/共享层/) |
| `backend/` | 数据端共享后端：接入 / 存储 / 分析 / 账号 | [数据端](../规划/数据端/) |
| `collection/` | 采集层：参考 SDK + 本地转发服务 | [接入契约](../规划/数据端/接入契约.md) |
| `integrations/` | **存放各个工具**：每个接入工具的适配/配置（工具本体不在此） | [执行计划 Phase 5](../规划/总则/执行计划.md) |
| `apps/user-portal/` | 使用端 · 使用者门户 | [使用端/工具门户](../规划/使用端/工具门户.md) |
| `apps/admin-dashboard/` | 数据端 · 后台分析台 | [架构与原则](../规划/总则/架构与原则.md) |
| `docs/` | 部署后承接 SSOT 的落地文档（现为空占位） | —— |
